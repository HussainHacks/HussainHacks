## Featured projects

- **OpenClue**: a local first desktop AI assistant for live meetings and interviews, in the style of Cluely. Electron, React and TypeScript up front, a Python FastAPI backend behind it, Faster Whisper transcription and RapidOCR screen context, with Ollama for fully local inference or OpenAI, Anthropic and Gemini when you want them. Runs on Windows, macOS and Linux. Source available under the Business Source License 1.1.
- **ProductSuite**: seven full stack apps built as one suite: FormForge (forms), TaskForge (tasks), PlanForge (kanban), BookForge (bookings), DataForge (custom lists), BoardForge (whiteboard) and StoryForge (stories). Every app is a FastAPI backend with a React and TypeScript frontend over shared authentication, database and testing packages, with tests and passing production builds across the suite.
- **LeadCaptureSoftware**: a multi tenant lead capture and conversion platform for HVAC contractors. FastAPI and Next.js, staff roles, a rules based qualification engine, conversation threads, appointments and analytics, with real Twilio SMS sending and a 146 test suite.
- **ClippingPipeline**: an end to end pipeline that monitors live streams and VODs, detects spike moments from chat velocity and audio energy, and cuts short vertical clips with burned in captions, titles and watermark. Zero language model tokens by design.
- **SportArb**: a real time sports arbitrage scanner in Python. It polls odds from multiple bookmakers, matches events across feeds, detects arbitrage opportunities through a set of risk filters, and sends paper trading alerts over Telegram, with Redis and PostgreSQL underneath and Docker on top.
- **GameSite**: Neon Arcade, a cyberpunk gaming portal with 16 real playable games, built mobile first.
